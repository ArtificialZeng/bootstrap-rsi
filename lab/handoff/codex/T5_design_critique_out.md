# T5｜对抗式实验设计审查

现有证据支持把 **4,096 token 内交付正确答案**作为主指标。它同时受答案质量、停止行为和输出格式影响。若冻结的权重编辑在留出题上稳定提高这个指标，就能支持该部署条件下的收益。要进一步声称“识别了截断机制”“推理能力改善”或“智能体自主发现了有效编辑”，还需要各自的对照。下文按这些声明的证据要求评定严重度。

审查时，汇总显示 1.7B 的 400 道留出题评估尚未完成，8B 可见的 smoke 记录以未作决定结束。现有可量化结果主要来自探索性练习。例如，1.7B 的 100 道练习题有 38 道截断、61 道答完且正确、1 道答完且错误。“38/39 个错误是截断”描述的是这个样本的记分构成。文中的复算只读现有记录，新增推理均为队列结束后的实验建议。依据 `out/results.md:6–10`、`out/mech_1.7b_summary.json:5–17`、`out/8bsmoke_results.json:1–9`。

## 1. 同题配对有效，共用批次种子的含义有限

- **问题。** 各臂按同一 `pid` 对齐，但每次批量调用只重置一次全局随机状态。MLX 对活动序列成批抽样，序列停止后会被移除，空位会补进新序列。编辑或提示改变任一序列的终止时机，就可能改变其他题在批次中对应的随机抽样。历史 40 题扫描还用了不同的初始种子与批次规模，底模从 100 题记录取子集，编辑另生成 40 题。依据 `common.py:42–56`、`agent8b.py:191–204`、`run.py:20–45`、`mech.py:115–130`、`handoff/protocol_spec.md:112–117`。本机 MLX-LM 0.32.2 的实现见 `../.venv/lib/python3.12/site-packages/mlx_lm/generate.py:1418–1428,1478–1517,1812–1864,2014–2017` 及同目录 `sample_utils.py:271–273`。
- **为什么重要。** 逐题差保留了相同题目及其难度，仍可描述本次运行的边际准确率差。逐题随机流的对应关系、单对答案的可重复性以及跨题依赖程度仍未知。当前逐题 bootstrap 和符号检验反映的是单套运行下的近似题目层面不确定性，无法涵盖跨种子波动。依据 `analyze.py:23–27,42–55`、`agent8b.py:191–204`。
- **现在／低成本补救。** 用缓存核对每臂 `pid` 的唯一性、覆盖和顺序，按题直接比较各臂，补报按输入顺序分块和题目难度分层的敏感性。队列后，在预先固定的小题集上使用每个 `(pid, 重复编号)` 单独维护的随机流，各臂共享对应流。用逐题运行或显式逐序列采样 key 实现。另在少量题做同种子底模重跑，核查实现可重复性。报告现有各臂的配对时，标为“同题、同批次初始种子”。
- **严重度。高。** 直接影响区间、检验和逐题轨迹的解释。

## 2. 单次 reseed 只给出一个对照差

- **问题。** 机制实验将底模种子 2000 与种子 1000 比较一次。编辑和这次 reseed 又共享 1000 的那一批底模作参照。依据 `mech.py:115–130`。
- **为什么重要。** 一次底模之差无法估计波动的分布或尾部概率。其绝对值大小和显著性无法裁决编辑是否有效。两个相对同批底模的差也相关，直接比较两列各自的 p 值会误判。
- **现在／低成本补救。** 报告 reseed 的逐题胜负、截断变化和区间。补报 `edit(1000) − base(2000)`，明确这是换底模参照的敏感性分析。队列后用至少三套预先指定的逐题种子重复 base 和 edit，报每套差、底模不同种子间的变动及按题汇总的区间。多套答案先在题内汇总，再以题为单位重采样。三套种子适合作为初检。若各种子间明显分歧，增加重复数或把结果限定在已观测种子。
- **严重度。高。** 单次小幅提升尤其容易受这一问题影响。

## 3. 准确率分解是记账恒等式，条件准确率受构成变化影响

- **问题。** 令 \(t\) 为截断率，\(a\) 为完成后准确率。`analyze.py` 的 \((t_b-t_e)a_b+(1-t_e)(a_e-a_b)\) 精确加总成总分差。改用编辑臂的 \(a_e\) 作完成率项的权重也成立，两个分项会重新分配。两臂的完成集合由干预和采样共同决定。依据 `analyze.py:1–5,18–20`、`common.py:77–89,109–117`。
- **为什么重要。** 条件准确率下降可以来自新增的难题完成。按 `pid` 复算入选的 40 题，22 道两侧都答对，14 道两侧都截断，3 道截断转答对，1 道截断转答错。总分差 +7.5 个百分点。汇总分解为 +10.0 和 −2.5 个百分点，第二项出现时，原来答完的 22 道仍全部答对。忽略选优和批次依赖，3 胜 0 负对应名义单侧 \(p=0.125\)，仅用于演示。复算依据 `out/practice_base.jsonl`、`out/sweep_L6_a1.0.jsonl`、`out/run.log:8–22`。
- **现在／低成本补救。** 用缓存交付每臂的 3×3 题目转移表，设 T 为截断、W 为完成且错、C 为完成且对。报告 \([n(T\to C)-n(C\to T)]/N\) 和 \([n(W\to C)-n(C\to W)]/N\)，两者恰好相加为分差。同时展示 T↔W 对截断率的影响。原分解保留为描述量，可补对称权重及区间。双侧都完成的题、或各难度层级的结果均可描述，机制归因需要额外的干预或预算交互证据。
- **严重度。高。** 直接决定“只是少截断”“完成后推理变差”等表述能否成立。

## 4. 到达上限、仍在思考、循环与省算力是不同指标

- **问题。** 当前用输出 token 数达到 cap 来记截断。循环标签还要求截断，并对末尾文本作压缩率判断。1.7B 练习集 38 个截断文本中，已有 9 个出现 `</think>`，因此“到上限”这个事件可发生在结束思考之后。入选扫描的截断率下降 10 个百分点，而均长约从 3,264 降到 3,253 token。依据 `common.py:77–89,109–117`、`agent8b.py:169–171`、`out/practice_base.jsonl`、`out/run.log:8–11`。
- **为什么重要。** 编辑可能减少较长的最终输出，改变 box 格式，或把一批答案移动到 4,096 附近的另一侧。截断率下降不足以单独支持“少进入循环”“计算开销下降”或“做题能力提升”。
- **现在／低成本补救。** 保持原主评分，从文本和 token 记录补报思考是否结束、最后一框是否完整且正确、最终答案缺失率，以及实际输出 token 的均值、分位数和每正确一题所用总 token。对截断输出中已出现的完整框做独立诊断。按 1,024／2,048／3,072／4,096 离线重裁已存轨迹，画完成率和准确率随 cap 变化的曲线，注明是固定轨迹重裁。若主张抑制循环，补固定位置窗口的重复度指标，并盲审少量改善和恶化轨迹。
- **严重度。中高。** 对固定预算总分属解释限制，对“修复循环”或“省算力”属主要证据缺口。

## 5. MATH-500 的留出隔离只覆盖本实验

- **问题。** MATH-500 是公开 MATH 题目的子集，Qwen3 技术报告也把它作为评测。报告描述了训练数据来源和部分训练阶段的相似性过滤，公开信息不足以逐题确认这些 checkpoint 在预训练、后训练或教师蒸馏中是否接触题面、解答或变体。是否存在污染及其规模不确定。按本地划分核对，500 个 ID 唯一，题面经 NFKC、大小写折叠并去空白后仍唯一。模板近重复仍可能存在。依据 `common.py:13,21–26`，本地数据快照 `6e4ed1a2a79af7d8630a6b768ec859cb5af4d3be/test.jsonl`。[MATH-500 来源说明](https://github.com/openai/prm800k) · [Qwen3 技术报告 §3.1、§4.1、§4.5–4.6](https://arxiv.org/html/2505.09388)
- **为什么重要。** 熟悉的题可能让完成答案的正确率接近天花板，令收益看起来主要来自完成率。熟悉度也可能缩短部分解题轨迹并降低截断。偏差净方向取决于何种题和解法被看到，不能由 98.4% 的练习集完成条件准确率倒推。
- **现在／低成本补救。** 用已有题面按主题、难度和跨组近重复候选做敏感性分析。可先对 LaTeX 和标点归一化，用文字相似度及数字模板筛候选，再人工复核。要外推到新题，用冻结的同一编辑，在有可核日期的新编或 checkpoint 发布后首次公开的题上复测，人工排除 MATH 题的改数或改写版本，保持评分及难度覆盖。若外部样本小，报区间并限制结论范围。
- **严重度。高。** 主要影响对未见数学题和一般推理能力的外推。

## 6. 练习题选层和强度允许样本外验证，仍需核对选择历史

- **问题。** 100 道练习题参与方向估计，前 40 道又用于择优。四个候选按准确率和截断率筛选。1.7B 队列中的 `--fixed 6,1.0` 固定的是已经赢得扫描的配方。旧 160 题脚本使用当前 400 道留出的前 160 道，日志止于进入评估。实际有无生成结果、谁看过、有无据此改变方案，现有记录无法确认。依据 `mech.py:60–112`、`queue.sh:7–10`、`run.py:13–17,36–56`、`out/run_160_aborted.log:22–23`。
- **为什么重要。** 若留出题和输出始终未参与选择，冻结配方在 400 题上的表现可检验这套选择流程是否泛化。40 题的胜者得分、选中的具体层和强度容易受偶然性影响。如果再从多个模型、对照、cap 或会话中挑最有利的结果，证据强度还会受到多重比较影响。
- **现在／低成本补救。** 记录数据版本、题 ID、候选、选择规则、种子、主要比较和访问历史。报告全部扫描以及三种尺寸结果。若曾按前 160 题结果决策，把这些题纳入探索分析，使用尚未接触的后 240 题或新题确认。下一次优化可在练习集内部把方向拟合与剂量选择分开，或交叉拟合检查配方稳定性。确认性比较采用事先指定的单一主对比，或对多项主张统一校正。
- **严重度。高。** 直接决定 400 题结果的确认性地位。

## 7. α=1 是强干预，横向对比还需核对实际扰动幅度

- **问题。** α=1 全额移除的是选中层两个输出矩阵沿 \(u\) 写入的分量。跳连及其他层仍可保留或产生同向成分。论文 α=0.05 是**第一协议第二次会话**的 layer 8 双矩阵编辑。第二协议 session 2 的方向编辑在 layer 63 减去 5 倍投影，session 8 则对所有 48 个线性注意力层的 time-step bias 加 0.5。论文的 4,096 token 用于相关会话及预留检查，+6.6 来自 16,384 token、490 题各 8 答的评估。依据 `common.py:136–148`、`mech.py:91–112`、`handoff/protocol_spec.md:180–189,224–244`。[原论文 v2 §3.4、表 1、§D.3、§E.9、表 13](https://arxiv.org/html/2611.21885v2)
- **为什么重要。** 在固定 \(W,u\) 且忽略转换舍入时，\(\|\Delta W\|_F=|\alpha|\,\|u^{\mathsf T}W\|_2\)。跨矩阵或模型只比较 α，无法衡量相对改动。强投影可能引起广泛行为变化，单剂量的成功不足以证明与论文小幅方向编辑有连续关系。1.7B、4B 和来自 8-bit checkpoint 的 8B 还存在不同模型来源与处理路径，三个点的差异无法单独归于参数规模。依据 `mech.py:23,48–51`、`agent8b.py:35–50`。
- **现在／低成本补救。** 队列后选一个冻结层和小题集，比较 α=0、0.05、一个中间剂量和 1。记录两个矩阵实际保存后的相对 Frobenius 改变量。资源允许时分别只动 `o_proj` 或 `down_proj`，确认哪个分量贡献变化。分别报告各 checkpoint 的效果，说明剂量和模型外推检验的覆盖范围。
- **严重度。高。** 对重现原机制、剂量相似性和规模解释影响大。

## 8. 全答案均值方向与单一随机方向无法鉴别特异性

- **问题。** \(u\) 来自截断与完成轨迹的全响应 token 残差均值。题目难度、语言和主题、生成位置、长尾重复、是否进入最终答案等因素都可能进入这个差。读出的是层后总残差，操作的是两路矩阵写入。当前随机对照只有一个方向，匹配层、α 和单位范数，每矩阵的实际扰动幅度依方向而变。依据 `mech.py:76–88,118–128`、`agent8b.py:149–166`、`common.py:136–148`。
- **为什么重要。** 对冻结方向的介入可以改行为。将其解释为“终止机制”还要求排除一般扰动、长度代理或题目组成。即使胜过这条随机方向，也仅约束了这一对照的效果。随机方向的一般表现还有待估计。
- **现在／低成本补救。** 缓存文本先做难度、答案阶段及长度诊断，逐题隐藏状态若未保存，方向去混杂需要重新读状态。队列后，在固定的共同早期 thinking 窗口，尽量用同题多种子中同时有截断和完成的轨迹估计方向，匹配位置，并在相同题型或难度层内置换标签作对照。预定 3–5 个随机方向作初筛。选相对扰动幅度接近的方向，或在预设剂量范围内逐矩阵匹配幅度。报告每个效果和直接的 edit−random 区间。可先用小题集筛查有无明显特异性，再决定样本规模。
- **严重度。高。** 对“找到了截断方向或原因”是核心威胁。

## 9. “Think efficiently”能检验一条提示，提示策略的总体比较仍有缺口

- **问题。** 简洁臂在相同采样、cap 与判分下追加一句短思考和避免重复的指令。原有的逐步推理指令仍保留。权重编辑用了四组候选选优，提示臂没有相当的练习集搜索。依据 `common.py:17–18,33–47`、`mech.py:95–110,124–130`。
- **为什么重要。** 这个条件能够回答这一句提示在当前模板中是否有效。泛称“权重改写优于提示”还涉及措辞、指令位置和实际 token 开销。同上限允许各臂用不同计算量。编辑显著、提示不显著时，两者差异仍需要直接检验。
- **现在／低成本补救。** 用现有缓存按题直接算 edit−concise 的差和区间，同时报告正确率、截断和实耗 token。下一轮用同数量练习题、同数量候选冻结提示，候选可含替换原后缀的简洁版，并设类似长度的中性提示以诊断追加效应。若要讨论可替代性，把更优的冻结提示与编辑并列，在相同 cap 和相近实耗 token 下比较。Qwen3 的思考预算控制可作为另一个明确改变解码策略的基线。[Qwen3 技术报告 §4.3](https://arxiv.org/html/2505.09388)
- **严重度。中。** 对“提示也能否做到”有用，声称权重编辑优于推理时控制时则升为高。

## 10. 固定前缀续写与一次 8,192 token 生成的关系有条件

- **问题。** 当前只把底模在 4,096 处被截断的序列取出，以旧 prompt 和完整输出 token 作固定前缀，重新成批预填充，以种子 3000 再抽最多 4,096 token。样本的前半程被锁定，批处理和随机流重新开始，编辑臂没有同样的延长预算对照。依据 `mech.py:133–151`、`common.py:42–56`、`analyze.py:57–62`。
- **为什么重要。** 若 cap 对前半程不可见，前缀分布吻合，重启前后的状态、数值与条件采样分布一致，则重新抽后缀在**分布上**可以等价于一次长生成。当前实现重新计算和抽取后缀，这些分布等价条件尚未验证。对一次无条件 8,192 生成，偏差符号不确定。相对从头重抽，固定前缀会保留卡住的路径，也会保留进展顺利的路径，因此在这两类前缀上的差可能方向相反。允许根据表现择优又是另一种策略。现在的数字直接对应“这一批固定前缀补抽一次”的策略。
- **现在／低成本补救。** 用已有续写记录报总体和按 cap 时状态分层的完成数、正确数及新增 token，注明续写条件。队列后预抽按难度、主题分层的一小批题，让 base 和 edit 都从头单程生成到 8,192。保留终止原因及 token，离线将每条长轨迹重裁到 4,096，比较编辑收益在两个 cap 的差，并在同批截断前缀补做条件续写。若额外预算的实际方案是“重试”，把它作为单独策略，以总 token 成本比较。
- **严重度。高。** 直接制约“增加预算就能解释编辑收益”的主张。

## 11. 8B 提示与工具脚手架改变了“自主发现”的归因

- **问题。** 本地系统提示明示残差输出所在的两个矩阵、形状和投影公式，起始诊断直接给截断、循环与失败 ID。论文公开转述也给出方向削弱、分组均值 helper，并要求查看失败。逐字原始提示未公开，实际提示强度的差距不确定。依据 `agent8b.py:443–472`、`handoff/protocol_spec.md:10–13,25–39,101–107`、`handoff/review_agent8b.md:281–288`。[原论文 v2 §D.4](https://arxiv.org/html/2611.21885v2)
- **为什么重要。** 8B 成功可以证明冻结的编辑者在指定工具集内为其执行副本选出有效编辑。公式和矩阵角色来自脚手架，层、方向、剂量、分部测试和取舍有多少来自模型要由日志支持。会话使用练习题参考答案和反馈作搜索选择，各次从底模开始，因而适合检验无梯度权重编辑的可行性。持续累积式自改写或“自己比其他编辑者更会改”需要专门对照。依据 `agent8b.py:121–137,287–334,519–547,643–659`。
- **现在／低成本补救。** 按日志逐会话记录首个诊断、统计量与方向来源、层和剂量候选、分部测试和决策，并标注其先于还是晚于相关反馈。若主张自主搜索有额外收益，用同 60 道练习题、相同编辑空间和相近评估预算的冻结脚本直接对比。当前队列没有开启 agent 的 `script` 或 `reseed` 阶段，现成 8B 机制臂能作同题描述性对比，但方向用的是全部 100 道练习题，含 agent 的 40 道预留题，两分支还可能复用同一底模输出。若要估计提示贡献，可在相同工具、预算、会话种子下仅去掉对残差输出矩阵的强调。依据 `agent8b.py:500–502,535–547,562–569,596–641`、`mech.py:60–85`、`queue.sh:7–10`。
- **严重度。高。** 关系到自主发现、脚本比较和跨设置复现的表述。

## 12. 8B 的预留检查用于决策，发表依据应来自独立评估

- **问题。** 每会话用 40 道预留题各一答，单题就是 2.5 个百分点。三个会话共用题和检查种子，候选经练习搜索，再由检查筛选是否保留。准确率“未显著下降”在低功效下也容易出现。论文的预留检查为 256 题各两答，正式评估还有另一题集和更长预算。依据 `agent8b.py:458–462,480–487,564–582,643–659`、`handoff/protocol_spec.md:180–189,208–218`。
- **为什么重要。** 被选中的检查差容易偏乐观。三个会话不足以估计稳定成功率，且共享题和底模输出会造成相关性。Qwen3-8B 的投影搜索空间、预算、题库和 Qwen3.5-27B 的线性注意力编辑条件均不同。一项成功可以支持本设置下的存在性，一项失败主要说明这一流程在所测会话中未产生已确认收益。依据 `agent8b.py:31–32,69–72,568–569,596–610,643–659`、`handoff/protocol_spec.md:141–154,180–206,224–244`。
- **现在／低成本补救。** 固定会话数和主判据。用已有的逐题不一致率估计独立评估的精度。报告所有会话，分列有无候选、有无检查、确认、主动撤回、耗尽未决定和独立留出成绩。若估计完整提交策略的收益，可把撤回后继续使用底模的增益记作 0，再报告各次的策略增益；若以任一提交成功为主张，对可进入确认的会话比较做预定校正。若必须支持“准确率非劣”，事先设可接受损失 \(\delta\)，以置信下界高于 \(-\delta\) 作证。把 8B 结果定位为小规模协议迁移。
- **严重度。高。** 影响 8B 正负结果的可信度及其与论文的对应关系。

原论文的 session 8 可以做一个描述性校准。同一 490×8 口径下，若按截断得零分，公开四舍五入的准确率 57.2%→63.8% 和截断率 33.6%→26.1% 隐含完成条件准确率约 86.1%→86.3%。按本项目的权重顺序近似分解，完成率项约 +6.46 个百分点，条件准确率项约 +0.14 个百分点。精度受原表舍入限制。这是与本项目假设相容的汇总模式，逐题归因与底层机制仍需另外验证。[原论文 v2 §D.3、§E.9、表 13](https://arxiv.org/html/2611.21885v2)

## 发表前必须做的三项

1. **锁定留出与主要检验，完成可重复的同题比较。** 查清旧 160 题的实际使用，冻结配方、题 ID、主比较及会话数。在未用于选择的题上用至少三套预定的逐题随机流复核 base/edit，同时报告 seed 级效果、按题区间、3×3 转移和全部候选或会话记录。建议把 4,096 总准确率作为主结果，按明确的适用条件解释。
2. **用小样本做能区分机制的干预。** 在一组预定题上比较弱剂量与 α=1、多个扰动幅度可比的随机方向，以及 base/edit 单程 8,192 后重裁至 4,096。补报实际 token、停止状态和格式指标。若证据只支持在固定预算下更常交付正确答案，发表结论可据此收窄。
3. **给外推与自主性的主张配对应证据。** “适用于新数学题”用有日期和近重复审查的独立题集确认。“智能体搜索有额外贡献”用等练习和等评估预算的脚本对照与完整会话轨迹确认。若只发表本基准上的编辑效果与 8B 可行性，明确使用的是公开 MATH-500、带提示和工具脚手架的小规模协议迁移。
